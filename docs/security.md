# Security model

V0.1 accepts only declarative candidate descriptors validated against fixed allow-lists. It does not load, compile, or execute source generated by agents. Candidate implementations are trusted package code.

The worker process provides fault containment, not a security boundary. It inherits the host user's filesystem and network permissions. Do not use it to execute hostile or untrusted code.

Before arbitrary code execution, add a fail-closed OS/container sandbox: unprivileged identity, minimal isolated filesystem, network disabled, CPU/memory/process/file-size quotas, bounded logs, syscall restrictions where available, and reliable teardown. Never expose credentials, home directories, SSH keys, cloud tokens, or host sockets.
